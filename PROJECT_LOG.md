# Журнал проекта RH Portfolio

## 2026-09-03 — запуск проекта

- Создан проект мини-сайта для портфеля кошелька `0x85D62cDb64bAEcdFAC953889bC28A952815b950A` в Robinhood Chain.
- Источник транзакций: вкладка Blockscout `Transactions` (`?tab=txs`). Общий поток `Token Transfers` не используется как список сделок из-за спама.
- Для каждой транзакции разрешено читать token-transfer events только внутри уже отобранного хеша транзакции.
- FRONG объединён из четырёх покупок, включая покупки связанными адресами `0xf70d…dbEF`, `0x0EC4…038F` и транзит через `0x7158…6b0b`.
- Зафиксировано: куплено `1 223 578,3351708914 FRONG`, продаж не было, себестоимость `≈1,9717751058 ETH`.
- Текущая оценка строится по чистому исполнимому выходу полной продажи позиции, а не по графиковой цене.
- Формула PnL: `выручка от продаж + чистая оценка остатка − полная себестоимость`.
- Внутренние переводы между связанными адресами не считаются повторной покупкой или продажей.
- Таблица сортируется по текущей оценке позиции в ETH по убыванию.
- Выбран публичный GitHub-репозиторий `rh-portfolio` и публикация через GitHub Pages.
- Реализован адаптивный тёмный дашборд с ключевыми метриками, сортировкой позиций по текущей оценке и прямыми ссылками на Blockscout/Matcha.
- Добавлен автоматический сценарий обновления: проверка 44 транзакций, получение MCap/цены из Blockscout и исполнимой котировки из 0x Swap API при наличии секрета `ZEROX_API_KEY`.
- Добавлен GitHub Actions workflow: обновление каждые 15 минут со смещением от начала часа, ручной запуск, сборка и публикация GitHub Pages.
- Плановые обновления публикуют новый Pages-артефакт без автоматических коммитов каждые 15 минут, чтобы история Git не засорялась техническими снимками.
- В случае временной недоступности внешнего API сохраняется последнее успешное значение, чтобы сайт продолжал работать.
- Локальный статический экспорт успешно сформирован. Под Windows Vinext 1.0.0-beta.5 возвращает ошибку libuv уже после завершения экспорта; на GitHub Actions используется Linux, где этот Windows-runtime дефект неприменим.
- Создан публичный репозиторий `talkhardtalk/rh-portfolio`.
