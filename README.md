# RH Portfolio

Мини-сайт с проверенными позициями кошелька в Robinhood Chain.

## Принципы расчёта

- исходная история сделок проверена по Blockscout `Transactions`, а не по общему списку token transfers;
- новые покупки автоматически находятся по RPC: учитываются только транзакции, отправленные самим кошельком с расходом ETH, поэтому входящий спам отбрасывается;
- связанные кошельки учитываются через проверенные правила атрибуции;
- текущая оценка — выход полной продажи по маршруту `BEST_PRICE` официального Uniswap Trading API;
- текущая капитализация — DexScreener по наиболее ликвидной репрезентативной паре; для новых токенов заведомо тонкий ETH/USDG-пул не перебивает существенно более ликвидный рынок;
- PnL включает реализованный и нереализованный результат.

Подробные решения и изменения находятся в [PROJECT_LOG.md](PROJECT_LOG.md).

## Обновление данных

- GitHub Actions остаётся единственным местом, где выполняются расчёт, сборка и публикация.
- Cloudflare Worker каждые 10 минут независимо вызывает существующий `workflow_dispatch`; GitHub Actions получает секреты, обновляет данные и публикует сайт.
- Кнопка «Обновить данные» запускает тот же workflow вручную. Worker не создаёт параллельные запуски и выдерживает пятиминутный интервал между ними.
- Встроенный часовой cron GitHub остаётся резервным каналом на случай сбоя внешнего триггера; локальный watchdog Codex остановлен.
- Для исполнимых котировок GitHub Actions использует секрет `UNISWAP_API_KEY`; регулярные запросы к 0x отключены.
- Последний опубликованный снимок доступен также в машиночитаемом виде по `/rh-portfolio/portfolio.json`; он содержит только те же публичные сведения о кошельке и позициях, которые выводятся в таблице.

Исходники и инструкция облачного триггера находятся в [watchdog](watchdog/README.md).
